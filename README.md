## 📌 Project Overview

This project performs **Exploratory Data Analysis (EDA)** on the **Netflix Titles Dataset** to uncover meaningful insights into Netflix's global content library. The analysis explores trends in movies and TV shows, content distribution, ratings, genres, release years, and country-wise availability using Python and data visualization techniques.

The objective is to transform raw data into actionable insights through data cleaning, exploration, and visualization.

---

## 📂 Dataset

- **Dataset:** Netflix Titles Dataset
- **Source:** Kaggle
- **Records:** 8,800+ Netflix titles
- **Features:** 12+

The dataset includes information such as:

- Show ID
- Title
- Type (Movie / TV Show)
- Director
- Cast
- Country
- Date Added
- Release Year
- Rating
- Duration
- Listed Genres
- Description

## 📌 Key Insights

- Movies make up the majority of Netflix's content library.
- The United States contributes the highest number of titles.
- TV-MA is the most frequently assigned content rating.
- Netflix experienced rapid content growth after 2015.
- Drama and International Movies are among the most common genres.
- Most missing values are found in the Director and Cast columns.

## 🚀 Getting Started

### Clone the repository

```bash
git clone https://github.com/HelloApurva/netflix-data-analysis.git
```

### Navigate to the project

```bash
cd netflix-data-analysis
```

```bash
pip install -r requirements.txt
```

```bash
jupyter notebook
```

Open:

